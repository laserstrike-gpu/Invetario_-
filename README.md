# 📦 Inventario 3

Aplicación web desarrollada con **HTML, CSS y JavaScript** para administrar un inventario de productos. Permite realizar operaciones CRUD completas, validar datos, buscar productos y guardar la información de forma persistente utilizando **LocalStorage**.

## 🚀 Funcionalidades

- ➕ Agregar productos al inventario.
- ✏️ Editar productos existentes.
- ❌ Eliminar productos seleccionados.
- 🔍 Buscar productos por nombre en tiempo real.
- 📌 Seleccionar productos para editarlos o eliminarlos.
- 💾 Guardar automáticamente el inventario en LocalStorage.
- 🔄 Recuperar la información al volver a abrir la aplicación.
- 🚫 Evitar productos duplicados por nombre.
- ✅ Validar campos obligatorios.
- ✅ Validar que precio y stock sean numéricos.
- ✅ Validar que precio y stock sean mayores que cero.
- 🎨 Resaltar visualmente el producto seleccionado.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (ES6)
- LocalStorage
